# portfolio


This portfolio showcases my skills, projects, and development journey through a modern full-stack web application. It includes a secure admin dashboard for managing projects, Cloudinary-powered image uploads, JWT authentication, live GitHub and LeetCode integrations, responsive UI, dark/light mode, and smooth animations. The application is built with React, Node.js, Express.js, MongoDB, and Tailwind CSS, following a scalable component-based architecture.
